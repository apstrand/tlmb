
# What is mailbox

A self contained imap & smtp client application. Implemented in rust with cli, tui, tui and native mobile interfaces.
It is fast and lean, combining the best features of existing clients without the bloat. Supports multiple accounts but minimal configuration. Multiple running instances work well together, e.g. one on mobile, one on desktop, and cli/tui interactions.

# Platforms

Linux, MacOS, iOS, Android and web.

The web interface is built into all apps, so you start start it with e.g. "mailbox --serve" and you have a web app.

User interface can mimic mutt (tui) and spark (gui). Just standard unified inboxes with fast search and filter. Compose should allow easy selection of originating email address (seamless multi account support).
